# Перевод с экрана

В меню выбери **«Перевод с экрана»** и обведи область с текстом. Результат появится поверх выбранного места. Это статический снимок: прокрутка или изменение исходного окна не обновляют перевод.

Тонкая рамка обозначает границы снимка. Панель рядом с ним позволяет переключиться между оригиналом и переводом, скопировать картинку или текст, выбрать новую область и закрыть результат. Рамка и панель не попадают в скопированную картинку.

| Действие | Клавиши |
| --- | --- |
| Отменить выделение или закрыть результат | Esc или правая кнопка мыши |
| Скопировать выбранный вариант картинки | Ctrl+C |
| Скопировать текст выбранного варианта | Ctrl+Shift+C |

Пункт можно скрыть и переместить в **«Оформление → Пункты меню»**.

## Обработка данных

Для перевода требуется интернет. До подтверждения выделения показывается уведомление об отправке снимка в онлайн-сервис. Отправляется только выбранная область, без остального экрана. Во время захвата островок временно скрывается.

Снимки и переводы не сохраняются в историю или файлы. Буфер обмена изменяется только по нажатию пользователя. Приложение не читает браузерные профили и использует отдельную анонимную сетевую сессию.

Обработка запускается вручную. Есть отмена и общий сетевой таймаут 40 секунд. Ошибка отображается внутри островка; повторное выделение доступно той же кнопкой. Высота панели зависит от длины сообщения.

## Реализация

- Максимальная сторона отправляемого изображения — 2400 пикселей.
- Начальная сессия загружается с `https://translate.yandex.ru/ocr`.
- `/ocr/v1.1/recognize` возвращает текст, блоки, строки, цвета и геометрию.
- Параграфы переводятся одним запросом `/api/v1/tr.json/translate`, целевой язык — русский, формат — plain. Количество ответов проверяется перед отрисовкой.
- Старые надписи закрываются по геометрии строк и цвету фона, перевод отрисовывается средствами WPF. Свободное однотонное место справа используется до уменьшения шрифта. На сложных фонах возможны следы очистки.
- Истёкшая сессия обновляется один раз. Для ограничения запросов или капчи бесконечных повторов нет.
- Размеры ответов, число блоков и длина текста ограничены. Перенаправления не следуются автоматически. Ответы не исполняются как HTML или JavaScript.
- Данные сессии, полные URL запросов, снимки и распознанный текст не записываются в журнал ошибок.

## Проверки

```powershell
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --image-translation-tests artifacts/image-translation
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --image-translation-live artifacts/image-translation-live
```

Первый режим использует поддельный HTTP и проверяет протокол, отмену, ошибки, меню и панель результата. Второй дополнительно проверяет нативный захват тестового окна и отправляет только автоматически нарисованную картинку, не пользовательский экран.
