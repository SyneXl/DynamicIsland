# Перевод с экрана

В меню выбери **«Перевод с экрана»**, укажи **Яндекс** или **Google**, нажми **«Выделить область»** и обведи текст. Выбор сохраняется; по умолчанию остаётся Яндекс. **Ctrl+T при наведении на остров** сразу запускает выделение с выбранным переводчиком; сочетание можно изменить в «Настройки → Горячие клавиши».

Результат появится поверх выбранного места. Это статический снимок: прокрутка или изменение исходного окна не обновляют перевод.

Во время выделения фон мягко затемняется, границы отмечены тонкой контрастной рамкой с уголками; рядом показан размер области в физических пикселях. Рамка следует мыши без задержки. Если выделение или курсор перед его началом пересекает островок, тот становится почти прозрачным и не перехватывает мышь. При уходе из его зоны прозрачность восстанавливается.

После выделения область остаётся видимой во время запроса: по рамке движется небольшой световой акцент. Готовый перевод плавно появляется в той же области; постоянная анимация останавливается. Панель рядом позволяет переключиться между оригиналом и переводом, скопировать картинку или текст, выбрать новую область и закрыть результат. Рамка, эффекты и панель не попадают в скопированную картинку.

Островок также не перекрывает расположенный под ним результат: до закрытия такой области он остаётся приглушённым. Отмена, ошибка и закрытие восстанавливают прозрачность и обработку мыши. Системная настройка отключения анимации учитывается; повторяющегося эффекта в готовом результате нет.

| Действие | Клавиши |
| --- | --- |
| Отменить выделение или закрыть результат | Esc или правая кнопка мыши |
| Скопировать выбранный вариант картинки | Ctrl+C |
| Скопировать текст выбранного варианта | Ctrl+Shift+C |

Пункт можно скрыть и переместить в **«Оформление → Пункты меню»**.

## Обработка данных

Для перевода требуется интернет. До подтверждения выделения показывается уведомление об отправке снимка в онлайн-сервис. Отправляется только выбранная область, без остального экрана. Во время захвата островок временно скрывается.

Снимки и переводы не сохраняются приложением в историю или файлы. Буфер обмена изменяется только по нажатию пользователя. Приложение не читает браузерные профили. Снимок отправляется только выбранному переводчику: автоматического перехода на другой сервис при ошибке нет.

Настройка `ImageTranslationProvider` хранится вместе с остальными параметрами в `HKCU\Software\DynamicIsland` (`0` — Яндекс, `1` — Google). Ошибка сохранения не меняет выбранный сервис. Пока перевод выполняется, переключатель скрывается; текущая операция всегда использует переводчик, выбранный при запуске.

Обработка запускается вручную. Есть отмена и общий сетевой таймаут 40 секунд. Ошибка отображается внутри островка; повторное выделение доступно той же кнопкой. Высота панели зависит от длины сообщения.

## Реализация

- Максимальная сторона отправляемого изображения — 2400 пикселей.
- Яндекс: начальная сессия загружается с `https://translate.yandex.ru/ocr`; `/ocr/v1.1/recognize` возвращает текст, блоки, строки, цвета и геометрию. Параграфы переводятся одним запросом `/api/v1/tr.json/translate`, целевой язык — русский, формат — plain. Количество ответов проверяется перед отрисовкой.
- Google: один protobuf-запрос Chromium Lens с фильтром перевода на русский. HTML поиска, браузер и cookies не используются. Геометрия OCR связывается с переводом по идентификаторам, а не по порядку блоков. [Исследование и ограничения](google-image-translation.md).
- Цвета Яндекса восстанавливаются по `backgroundColor.Points` и `textColor.Points`: медиана пикселей исходного цветного снимка, а не RGB распознавателя, которые могут быть серыми. До 64 точек на цвет; некорректные координаты и прозрачные пиксели отбрасываются. Без пригодных точек используются цвета OCR. Google сохраняет переданные им цвета.
- Старые надписи закрываются по геометрии строк и восстановленному цвету фона, перевод отрисовывается средствами WPF. Измеряется полный текст без автоматических многоточий: короткие подписи остаются в одну строку, абзацы сохраняют переносы. Свободные однотонные отступы используются без пересечения соседних надписей, значков и границ. Близкие подписи одного ряда получают общий размер шрифта и выравнивание; логотипы, заголовки и абзацы под них не подстраиваются. В тесной области шрифт всё ещё может быть уменьшен; полный перевод доступен для копирования. На фотографиях и градиентах возможны следы очистки: генеративного восстановления фона нет.
- Исходный снимок делается до показа рамки обработки; на время захвата скрываются и островок, и отдельный нативный стеклянный фон. Закрытие области во время запроса отменяет его, поздний ответ не создаёт новое окно. Готовый результат не отменяет уже завершённый запрос при закрытии.
- Истёкшая сессия Яндекса обновляется один раз. Для Google нет автоматических повторов; при 403/429 действует пауза с учётом `Retry-After`. Для ограничения запросов или капчи бесконечных повторов нет.
- Размеры ответов, число блоков и длина текста ограничены. Перенаправления не следуются автоматически. Ответы не исполняются как HTML или JavaScript.
- Данные сессии, полные URL запросов, снимки и распознанный текст не записываются в журнал ошибок.

## Проверки

```powershell
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --image-translation-tests artifacts/image-translation
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --image-translation-live artifacts/image-translation-live
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --google-image-translation-tests artifacts/google-image-translation
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --google-image-translation-live artifacts/google-image-translation-live
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --translation-polish-tests artifacts/translation-polish

dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --translation-layout-tests artifacts/translation-layout
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --translation-polish-live artifacts/translation-polish-live
```

Режимы `*-tests` используют поддельный HTTP и проверяют протокол, отмену, ошибки, меню и панель результата. Режимы `*-live` дополнительно отправляют автоматически нарисованную картинку, не пользовательский экран. Яндекс live также проверяет нативный захват тестового окна. Сетевые live-проверки не запускаются в CI.
