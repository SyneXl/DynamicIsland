# Google: перевод области экрана

## Выбранный путь

Один `POST https://lensfrontend-pa.googleapis.com/v1/crupload`, `application/x-protobuf`. В запросе — снимок выделенной области, размеры, новый случайный request ID, locale и фильтр `TRANSLATE` (`source=auto`, `target=ru`). Используется публичный клиентский ключ Lens из Chromium, не ключ аккаунта пользователя. Cookies и авторизация отсутствуют. Установка расширения или браузера не нужна.

Ответ содержит OCR и перевод. Параграфы сопоставляются с DeepGleam по идентификаторам; единственный блок без ID поддерживается отдельно. Несовпавшие идентификаторы, неверный целевой язык, неполный перевод и неизвестная геометрия не подменяются «похожим» результатом. Координаты ограничиваются изображением; размер ответа, глубина protobuf, количество блоков/строк и длина текста имеют пределы.

`NO_OP_TRANSLATION` (9) — штатный результат «оставить без изменений», а не ошибка `EMPTY_TRANSLATION` (8). Числа, названия моделей и символы с этим статусом сохраняют исходный текст для копирования и исходные пиксели на картинке. Так же сохраняются блоки `SAME_LANGUAGE` (4) и `UNKNOWN_SOURCE_LANGUAGE` (5): если сервис не определил язык конкретного элемента, он остаётся исходным и не отменяет остальные переводы. [Значения статусов в исходниках Chromium](https://github.com/chromium/chromium/blob/main/third_party/lens_server_proto/lens_overlay_deep_gleam_data.proto).

Числовой или символьный блок определяется по самому распознанному содержимому, а не только по статусу сервера: без букв перевод ему не требуется. Проверка использует Unicode runes, поэтому учитывает цифры разных письменностей, emoji и буквы за пределами BMP. Операционные ошибки (`SERVER_ERROR`, `INVALID_REQUEST`, `DEADLINE_EXCEEDED`), неизвестные коды статуса и неверный целевой язык не маскируются этим правилом. Пустой перевод обычного буквенного текста по-прежнему отклоняется.

Оба переводчика используют существующую локальную отрисовку WPF поверх снимка. Это не точная копия рендера Lens: серверные WEBP-патчи восстановления фона пока не используются. На однотонном фоне результат выглядит аккуратно; на фотографиях/сложном фоне могут оставаться следы замены текста.

## Ошибки и нагрузка

- Сеть используется только после ручного выделения. Открытие настроек и выбор переводчика запросов не создают.
- Нет автоматических повторов, перенаправлений, ротации прокси, решения CAPTCHA или смены сервиса без выбора пользователя.
- При 403/429 — короткая ошибка и пауза 30–900 с, учитывающая `Retry-After`. Новый запрос возможен только вручную после паузы.
- Общий таймаут — 40 с, есть отмена. HTML вместо protobuf, ошибки HTTP и повреждённый ответ показываются как ошибка, а не открываются в браузере.
- Этот endpoint не является документированным стабильным публичным API для сторонних приложений. Протокол/ключ могут измениться; полное отсутствие блокировок или CAPTCHA гарантировать нельзя. Поддержка не строится на обходе таких проверок.

Проверки протокола и интерфейса находятся в `Tests/GoogleImageTranslationTests.cs`. Их HTTP-подмены работают без сети; отдельный `--google-image-translation-live` выполняет запрос только с автоматически нарисованным тестовым изображением.
