# Приглушать без наведения

**Оформление → Приглушать без наведения.** Опция выключена по умолчанию. Выбор сохраняется в `HKCU\Software\DynamicIsland\QuietWhenIdle` (`DWORD`, 0/1). Кинорежим настраивается отдельно.

Компактные часы, погода, медиастраница, таймер и запись OBS сохраняют обычные размеры и содержимое. Нового ограничения длины текста нет: остаётся обычная медиастраница, а не сокращённая `CinemaMedia`. Сохраняются стандартные ограничения ширины и прокрутка текста.

После 650 мс без наведения весь компактный остров за 240 мс переходит к 40% непрозрачности. Это относится и к тексту, погоде, иконкам, обложке, эквалайзеру и боковому пузырьку: ярких исключений нет. Чёрный фон дополнительно ослабляется до 55% внутри общего слоя — итоговая непрозрачность фона 22%. Обложка получает дополнительное ослабление, цветовые акценты становятся нейтральными. Эквалайзер остаётся живым: плавно уменьшающаяся амплитуда, сглаживание и максимум 30 кадров/с в спокойном состоянии. Выбранный вид «Полоски»/«Матрица» сохраняется. В простое без медиастраницы цикл визуализации не работает.

Наведение на остров или боковой пузырёк возвращает обычный вид за 180 мс. Переход через промежуток между ними не вызывает мгновенного повторного приглушения. Движение, клики, удержание, перенос файлов и клавиатурный фокус блокируют приглушение.

Меню, раскрытые панели и плеер, регулировка громкости, уведомления, загрузка обновления, звонок таймера и последние десять секунд работающего таймера остаются в обычном виде. После их завершения начинается новая задержка. При скрытом/отправленном за край острове эффект не активируется.

В полноэкранном видео приоритет у прежнего кинорежима с его размерами и прозрачностью. Эффекты не перемножаются. Приглушённый вид временно скрывает DWM-подложку «Стекло», восстанавливая её при наведении или открытии панели. Сам эффект использует обычную WPF-прозрачность и не зависит от Windows 11. Захват изображения экрана, анализ фона и определение отсутствия пользователя не применяются.

Отложенное действие создаётся только для ожидающего перехода, отменяется при взаимодействии и закрытии. Уже поставленный в очередь callback не отменяет выход из приложения. Повторные обновления состояния не переносят срок приглушения и не создают новый цикл опроса.

| Before | After | Why |
| --- | --- | --- |
| Компактный остров всегда контрастно-чёрный | Необязательное приглушение без наведения | Выбор внешнего вида без изменения привычного режима по умолчанию |
| Для тихого вида подошёл бы только кинорежим с сокращённой медиастраницей | Отдельное оформление обычной медиастраницы | Текст и геометрия не теряются |
| В 1.32.0 фон сохранял 58% непрозрачности, текст — 90% | Общий слой 40%, итоговый фон 22% | Приглушение действительно заметно; текст больше не выделяется почти полной яркостью |
| Боковой пузырёк имел отдельный уровень приглушения | Один общий слой с основным островом | Надписи и значки приглушаются одинаково, без двойного ослабления |
| Немедленное приглушение после ухода мыши могло бы мигать | Задержка с отменой и общий hover острова/пузырька | Спокойное взаимодействие |
| Общая настройка могла бы затронуть меню и сигналы | Явные исключения и приоритет кинорежима | Управление и важные события сохраняют читаемость |

Проверка:

```powershell
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --quiet-appearance-tests artifacts/quiet-appearance
```

Проверяются задержка, отмена, сохранение текста/размеров, hover, боковой пузырёк, таймер, запись OBS, уведомления, восстановление обычного вида и прежний кинорежим. WPF-снимки строятся на светлом и тёмном тестовом фоне; альфа реальных отрисованных пикселей проверяется отдельно, включая самые яркие надписи и значки. Настройки подменяются только в памяти процесса теста; реальные медиасессии, VPN и буфер обмена не используются.
