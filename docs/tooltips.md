# Подсказки

Подсказки используют встроенный **SF Pro Text 12 px**, тёмную карточку со
скруглением 11 px и тонким полупрозрачным контуром. Ширина ограничена 280 px;
текст переносится, а необычно длинные пути не растягивают карточку на весь экран.
Нормальные пояснения сокращены до одной-двух строк. Командная строка WinWS
больше не используется как подсказка к статусу Zapret.

При наведении нужно задержаться на элементе **1,2 секунды**. При переходе на
соседний элемент задержка повторяется: стандартный быстрый показ соседних
подсказок отключён (`BetweenShowDelay = 0`). Время чтения — 6 секунд.
Нативное поведение WPF, в том числе клавиатурная доступность, сохраняется.

`IslandToolTips` задаёт значения по умолчанию для `FrameworkElement`, поэтому
они действуют не только для XAML, но и для строк, создаваемых позднее в C#.
Задать attached properties только на Window было бы недостаточно: эти
свойства не наследуются его дочерними элементами.

## Исправление перекрытия

Подсказка WPF — отдельный HWND. В исходном варианте этот HWND не принадлежал
окну островка. Нативный эксперимент воспроизвёл проблему: после
`Native.KeepOnTop` подсказка оказывалась ниже островка.

При открытии `IslandToolTips` применяет общий стиль и связывает popup с HWND
островка через `GWLP_HWNDPARENT`. После штатного поднятия окна и размещения
стеклянного фона поднимается текущая подсказка с `SWP_NOACTIVATE` и
`SWP_NOOWNERZORDER`. Фокус, курсор и клавиатура не захватываются.

Клик, прокрутка, Escape, смена страницы, перемещение, скрытие и закрытие окна
убирают открытую подсказку. Закрытие очищает ссылку на текущий popup.
Фоновый таймер для каждой подсказки не создаётся: задержкой и временем чтения
по-прежнему управляет WPF.

| Before | After | Why |
| --- | --- | --- |
| Светлая системная полоска | Компактная тёмная карточка со SF Pro | Согласованность с островком |
| Длинные объяснения и полная командная строка | Короткие действия; пути — только там, где нужны | Меньше шума |
| Соседняя подсказка могла появляться сразу | Полная задержка 1,2 с на каждом элементе | Не мешает обычному движению курсора |
| Подсказка уходила за окно после очередного поднятия | Явный владелец popup и согласованный Z-order | Стабильная видимость |
| Открытая подсказка могла пережить смену страницы | Закрытие при навигации и взаимодействии | Нет устаревших пояснений |

## Проверки

```powershell
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --tooltip-tests C:\PATH\tooltip-results
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --tooltip-layer-probe C:\PATH\layer.json
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --menu-window-test C:\PATH\ui-results
```

Нативные проверки создают настоящий popup HWND, проверяют его владельца,
положение после пяти поднятий островка, отсутствие смены foreground window,
отрисовку кириллицы из встроенного OTF, габариты и закрытие при взаимодействии.
Те же операции с Z-order воспроизводятся на исходном дереве до исправления.
Интеграции, реестр, VPN и автопинг не запускаются и не переключаются.

Основные источники: исходники WPF
[ToolTipService](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/ToolTipService.cs),
[PopupControlService](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/PopupControlService.cs)
и документация Microsoft
[SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos).
