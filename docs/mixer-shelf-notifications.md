# Микшер, полка и уведомление об обновлении

## Микшер

Открывается нажатием на громкость на главной, значком в компактном индикаторе громкости или пунктом меню «Микшер». Пункт изначально скрыт; включается в «Оформление → Пункты меню». Индикатор громкости виден три секунды после изменения и не исчезает под указателем.

Вверху общая громкость текущего стандартного устройства Windows, ниже приложения с открытыми аудиосессиями, включая приостановленные. Сессии одного исполняемого файла объединяются. Кнопка динамика отключает звук, ползунок меняет громкость. При клавиатурном фокусе стрелки меняют значение, Home/End задают 0/100%. Колесо над списком прокручивает список, а не меняет общую громкость.

Список опрашивается раз в секунду только при открытом микшере. COM-объекты сессий не сохраняются. Каждая команда проверяет устройство и заново находит точные instance IDs; смена устройства и завершение процесса не перенаправляют команду другому приложению. Устройства с индивидуальным выводом, отличным от стандартного вывода Windows, пока в этот список не входят.

## Полка

- «+» выбирает файлы, значок текста создаёт заметку, значок лотка вставляет содержимое буфера. Ctrl+V работает в открытой полке.
- Поддерживаются файлы/папки, Unicode-текст и изображения Bitmap. При нескольких форматах приоритет у файлов, затем изображения, затем текста. Содержимое буфера не отслеживается и не читается до явного действия.
- Нажатие на текстовую плитку открывает редактор. «Готово», Ctrl+Enter и переход на другую страницу сохраняют. Escape отменяет правку. «Копировать» копирует весь текст. В самом редакторе Ctrl+V вставляет текст обычным способом.
- Файлы по-прежнему являются ссылками на оригиналы. Заметки UTF-8 и вставленные PNG хранятся в `%LOCALAPPDATA%\DynamicIsland\Shelf`, а список — в прежнем `HKCU\Software\DynamicIsland\Shelf`.
- Удаление плитки/очистка не удаляют оригинальные пользовательские файлы. Удаляются только собственные файлы с GUID-именами внутри папки полки. Частные элементы остаются на полке после перетаскивания наружу, чтобы не удалить источник до завершения копирования получателем.
- Ограничения: 200 элементов, миллион символов в заметке, 16 миллионов пикселей в изображении. Повторная вставка одинакового текста не создаёт дубликат.

## Обновления

После обнаружения новой версии появляется уведомление на 4,5 секунды. Оно не прерывает открытые панели, другие уведомления, звонящий таймер или полноэкранный кинорежим. Определения присутствия пользователя нет.

Первый показ сворачивается в боковой пузырёк со значком обновления. Нажатие повторно показывает уведомление и сразу убирает пузырёк; повторный показ не создаёт новый. Нажатие на само уведомление открывает обновление. Под указателем уведомление не закрывается.

Состояние сохраняется в `%LOCALAPPDATA%\DynamicIsland\Updates\notification.json`: непросмотренный пузырёк восстанавливается после перезапуска, та же версия повторно не уведомляет. Открытие страницы обновления также считается просмотром. Проверки и установка по-прежнему выполняются через `Updater`, файл уведомления не является источником метаданных для загрузки.

## Проверки

```powershell
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --island-features-tests artifacts/features
# Только на компьютере с аудиоустройством: собственная бесшумная WASAPI-сессия.
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release --no-build -- --native-mixer-test artifacts/native-mixer
```

| Before | After | Why |
| --- | --- | --- |
| Обновление заметно только в настройках | Короткое уведомление и сохраняющийся боковой пузырёк | Пропущенное уведомление остаётся доступным без определения активности |
| Громкость на главной — только индикатор | Нажатие открывает микшер | Дополнительный пункт меню не обязателен |
| Индикатор исчезает через 1,6 секунды | Три секунды и удержание при наведении | Можно спокойно нажать значок |
| Полка принимает только файлы | Текстовые плитки, редактор и явная вставка | Одна полка для временных материалов без истории всего буфера |
| При обновлении списка могли бы пересоздаваться ползунки | Строки сохраняются, обновление откладывается на время захвата мыши | Ползунок не прыгает во время перетаскивания |

Основные интерфейсы Windows: [IAudioSessionControl2](https://learn.microsoft.com/en-us/windows/win32/api/audiopolicy/nn-audiopolicy-iaudiosessioncontrol2), [ISimpleAudioVolume](https://learn.microsoft.com/en-us/windows/win32/api/audioclient/nn-audioclient-isimpleaudiovolume), [WPF Clipboard](https://learn.microsoft.com/en-us/dotnet/api/system.windows.clipboard).
