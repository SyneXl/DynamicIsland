# Удержание меню после уменьшения

При уменьшении открытой страницы (в том числе после загрузки данных) остров
запоминает её прежние фактические границы на экране, если курсор остался за
пределами новой страницы. Пока курсор находится в прежней области,
автосворачивание не срабатывает. Ограничения по времени нет.

Вход курсора в уменьшившийся остров возвращает обычное поведение. Выход
за прежние границы запускает стандартную задержку сворачивания. Защита общая
для всех открытых страниц, учитывает ширину и высоту, масштаб и DPI экрана.

Зона существует только в логике автосворачивания: не расширяет окно, не
добавляет элементы интерфейса/области hit-test, не захватывает мышь и не
считается наведением для горячих клавиш. Положение курсора проверяется
раз в 80 мс только пока такая зона активна; после её снятия таймер останавливается.
Закрытие/скрытие острова, изменение расположения, масштаба или DPI очищают зону.

Проверки: `dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --menu-retention-tests artifacts/menu-retention`
