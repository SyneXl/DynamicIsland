# Throne и надёжная проверка обновлений

- Управление Throne через API: включение и выключение, выбор группы и сервера.
- Проверка задержки серверов с сортировкой по пингу, поиск и сохранение выбора.
- Автоматическое скрытие Throne без версии с поддержкой API; ручной выбор в редакторе меню имеет приоритет.
- Загрузка актуального установщика Throne, включая бета-версии, в системную папку «Загрузки». Проверка SHA-256 и запуск только по отдельной кнопке.
- Исправлена проверка обновлений островка при ограничении GitHub API: резервная проверка через официальную страницу релиза, без токенов и входа в аккаунт.
- Повторные проверки учитывают время восстановления лимита API. Проверка SHA-256, защита от подмены канала и откат при неудачном запуске обновления сохранены.

Для Throne включи API в его настройках интеграции, затем обнови подключение в разделе Throne островка. Текущие настройки TUN и системного прокси не меняются.

Если старая версия 1.29.1 уже упёрлась в лимит GitHub и не может проверить обновление, скачай `DynamicIsland.exe` из этого релиза вручную. В 1.30.0 этот случай обрабатывается автоматически.
