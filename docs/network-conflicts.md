# Throne и Zapret: запуск при конфликте

При запуске из островка проверяется актуальное состояние обеих интеграций. Если другая программа работает, прямо вместо блока запуска появляется вопрос **«Включён Zapret/VPN. Отключить?»**.

- **Да** — отключить другую программу, подтвердить её отключение, затем запустить выбранную.
- **Нет** — запустить выбранную, оставив другую работающей. Это осознанное разрешение на совместную работу, а не отмена запуска.
- Выход из раздела до ответа отменяет новый запуск. Уже подтверждённая операция продолжается при переходе между разделами.

Обработчик не следит за пользователем и не выключает программы автоматически в фоне. Он не перехватывает запуск из самого Throne, `service.bat` или других приложений. Throne проверяется через существующую API-интеграцию; при отсутствии интеграции не требуется устанавливать Throne ради Zapret. Установленный, но закрытый клиент не мешает запуску Zapret. При недоступном API работающего клиента состояние не выдаётся за «выключен».

Отключение Zapret использует существующий UAC-помощник: только служба `zapret` и проверенные процессы Zapret. Общие драйверы WinDivert, сторонние `winws` и другие VPN не выключаются. Отключение Throne — `DELETE /v1/connection`, затем проверка `GET /v1/status` до `idle`. Ответ `202`, успешное завершение помощника или название процесса сами по себе не доказывают отключение. Ожидание перехода ограничено; при ошибке новый запуск не выполняется.

Общий захват намерения блокирует повторные нажатия и конкурирующие запуски на время проверки, ответа и переключения. После ответа состояние читается повторно. Смена сервера уже работающего VPN и применение стратегии уже работающего Zapret не задают вопрос повторно; если интерфейс устарел и программа тем временем выключилась, эти действия проходят проверку как новый запуск.

## Интерфейс

| Before | After | Why |
| --- | --- | --- |
| Обе программы включались без предупреждения | Короткий вопрос с «Да» и «Нет» в блоке запуска | Явный выбор без отдельного системного окна |
| Новое сообщение могло бы раздвинуть всю панель | Вопрос заменяет тот же блок высотой 96 px | Пункты и курсор остаются на месте |
| Серая карточка с обводкой выделялась из интерфейса | Вопрос и кнопки прямо на фоне островка, без подложки и рамки; текст выровнен с пунктами ниже | Предупреждение выглядит частью раздела, а не вложенным окном |
| Повторные нажатия могли бы запустить две цепочки | Один запрос на время решения и переключения | Предсказуемый порядок операций |
| Моментальная подмена блока | Появление за 160 мс; с клавиатуры и без системной анимации — сразу | Мягкий переход без задержки управления |

## Локальная проверка

```powershell
dotnet run --project Tests/DynamicIsland.Tests.csproj -c Release -- --network-conflict-tests C:\Temp\island-network-conflict
```

Тесты используют поддельные API и службы, не переключают пользовательский VPN/Zapret и не запускают UAC. Проверяются оба направления, оба ответа, свежесть состояния, задержанный `idle`, ложный успех помощника, отказ/UAC, таймаут, повторные ответы, устаревшие кнопки, выход и закрытие окна. Снимки обоих вариантов сохраняются в папку результата.
